# NA排班系统

一个简单的排班工具，帮你快速安排学生值班。

## 快速开始

1. 打开 `Frontend.html` 就能用
2. 点击"导入无课表"上传Excel文件（格式参考示例文件）
3. 点击"开始智能排班"自动分配
4. 点击"导出排班表"保存结果

## 基本操作

**导入学生**
- 支持Excel/CSV格式
- 表格需要包含：姓名、星期、时间段、周次
- 系统会自动识别学生的空闲时间

**排班模式**
- **NA模式**：女生不去男生区，男生优先男生区，每人一周一班（可调整）
- **自定义模式**：无限制，灵活配置

**手动调整**
- 拖拽学生到任意位置
- 点击学生查看空闲时间
- 单双周拆分：点击格子的"单双周"按钮

**继续排班**
- 手动添加新学生后，点击"继续排班"只填充空位
- 不会影响已有的排班

## 设置说明

**每个性别单次排班人数**
- 最少1，最多1：一周一班
- 最少1，最多1.5：两周三班
- 最少1，最多2：一周两班

**区分性别**
- 勾选：男女分开排班
- 不勾选：不区分性别

## 常见问题

**排班结果不满意？**
- 调整"最少/最多人数"设置
- 使用"继续排班"补充空位
- 手动拖拽调整

**导入失败？**
- 检查Excel格式是否正确
- 确保有"周一"或"星期"等关键字
- 参考示例文件格式

**数据丢失？**
- 系统会自动保存到浏览器
- 关闭前会提示保存
- 建议定期导出备份
